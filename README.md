# Git Ignore

A simple project created while learning Git and GitHub.

## About

This project is used to understand how `.gitignore` works and how Git tracks and ignores files.

## Topics Covered

* Creating a `.gitignore` file
* Ignoring files and folders
* Tracking and untracking files
* Basic Git commands

## Technologies Used

* HTML
* Git
* GitHub
